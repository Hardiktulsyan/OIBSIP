# Password Generator (Python Programming, Task 3)

Generates a random password of the length and character types you choose.

## Features
- Length from 4 to 64
- Choose lowercase, uppercase, digits and symbols
- The password always contains at least one character from every type you choose
- Uses the secrets module, which is made for passwords

## Requirements
Python 3, no extra packages.

## How to run
`python password_generator.py`

## Files
- password_generator.py : the full program
