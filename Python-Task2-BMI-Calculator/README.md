# BMI Calculator (Python Programming, Task 2)

Takes weight and height, calculates BMI, shows the category and saves each result to a file.

## Features
- Checks that weight and height are valid numbers
- Categories: Underweight (below 18.5), Normal weight (18.5 to 24.9), Overweight (25 to 29.9), Obese (30 and above)
- Saves results in bmi_history.txt and lets you view your history by name

## Requirements
Python 3, no extra packages.

## How to run
`python bmi_calculator.py`

Formula: BMI = weight in kg / (height in metres x height in metres)
